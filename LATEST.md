## Причины HTTP 404 и безопасное решение

Оба настроенных Apps Script адреса — для отдельного контура и для действующего Б/У Sheets — при независимом GET возвращают HTTP 404 со страницей Google «Page not found». В сохранённых ошибках доставки отдельного контура также зафиксирован 404. Это отказ настроенного получателя до успешной обработки карточек; повторный запуск исторической пересылки его не исправляет.

Дополнительно выполнено чтение метаданных двух таблиц через Google Sheets API существующей серверной учётной записью: таблицы каталога бота и назначения отдельного контура. В обоих случаях получен 404 NOT_FOUND. Такой ответ сам по себе не различает удалённый документ, ошибочный идентификатор и отсутствие доступа. Утверждать, что таблицы точно удалены, оснований нет.

Для восстановления требуется доступ к действующему проекту Apps Script и целевым таблицам: проверить существование документов, права серверной учётной записи, актуальное развёртывание и разрешение на вызов. В рамках найденного серверного доступа работоспособный альтернативный адрес и доступная подтверждённая таблица не установлены. Подмена назначения догадкой не выполнялась.

Подготовленный безопасный порядок:
1. Восстановить доступ к исходным таблицам и подтвердить актуальный адрес развёртывания, сохранив прежние настройки для отката.
2. Проверить чтение метаданных, структуру листов и диагностический ответ без изменения автомобильных строк.
3. Сопоставить задания с последними версиями карточек; отдельно проверить 554 операции снятия строк и служебные записи.
4. Выполнить одну согласованную идемпотентную контрольную операцию с повторным чтением результата, не открывая массовый потребитель очереди.
5. Только затем отдельно определять объём возобновления. Массовая историческая запись, фотографии и пересчёт цен этим отчётом не запускались и не разрешаются автоматически.

Причина остановки установлена до уровня недоступных Google-получателей. Восстановление их существования, развёртывания или прав технически не завершено; очередь сохранена.
